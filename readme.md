# Fullmetal for Visual Studio Code

> A dark theme with vibrant and intuitive colors, crafted with alchemy.

Fullmetal styles VS Code's built-in Dotenv language and adds support for legacy
filenames such as `.env-sample` and `app.env.local`. You can uninstall the standalone
DotENV extension to use Fullmetal's highlighting for multiline values and
variable references.
